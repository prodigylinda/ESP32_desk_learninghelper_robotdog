# esp-hi

#### Description
ESP-Hi 是一款基于 ESP32-C3 的 超低成本 AI 对话设备，仅需最少的板级硬件即可实现拾音和发声，同步优化了软件，降低内存与 Flash 占用，在资源受限的情况下同时实现了唤醒词检测与多种外设驱动。
